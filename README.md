## 🌟 Overview

**NEXUS Cyber Command Center** is a personal display-screen application designed to create an immersive, futuristic cyber-operations experience combining Matrix terminals, cyberpunk visuals, military command dashboards, and Hollywood-style hacker displays.

## 🚀 Features

- **8-Stage Cinematic Boot Sequence**: Typing line animation, dynamic progress bar, hex streams, and system audio hum.
- **Central 360° Canvas Radar**: 60FPS sweep beam, node blips, vector lines, and HUD indicators.
- **Interactive Command Terminal**: Custom shell supporting `help`, `scan`, `radar`, `analyze`, `override`, `status`, `boot`, `demo`, `matrix`, `crt`, `panic`.
- **Area Signal Scanner & Device Matrix**: Radius selector (`25M` to `500M`) generating nodes, signal strength, and encryption levels.
- **Global Signal Map & Satellite Downlink**: Animated arc connections between global tech hubs and orbital satellite telemetry.
- **Surveillance Camera Grid & Biometric Scanner**: 4-feed surveillance grid with digital noise static and laser mesh facial verification.
- **Zero-Dependency Synthesized Audio**: Built using browser native **Web Audio API** (`AudioContext`) for typing clicks, radar pings, and alert sirens.
- **Global Keyboard Shortcuts**: `F` (Fullscreen), `T` (Terminal), `R` (Radar), `A` (Scan), `M` (Matrix Rain), `S` (Sound), `D` (Demo Mode), `ESC` (Reset).

## 💻 Getting Started

### Installation

```bash
git clone https://github.com/saumypandey745/nexus-cyber-command-center.git
cd nexus-cyber-command-center
npm install
```

### Development Server

```bash
npm run dev
```

### Production Build

```bash
npm run build
```
